# tuto 골든셋 평가 프로토콜 (v1.1)

## 구성
사용자가 직접 따라해 본 튜토리얼 3~5편. 각 편: (1) tuto 초안 가이드 생성 →
(2) 사용자 교정(누락 스텝 추가·오류 값 수정) → (3) 교정본을 레퍼런스로 확정
(`~/.yta/golden/<video_id>/reference.md`, 초안은 `draft-<날짜>.md`로 보존).

## 지표 (per-video 진단 — n≤5이므로 통계적 일반화 주장 금지)
### 스텝 재현율 (R1-Recall)
- 분모: 레퍼런스의 스텝 수. 분자: 초안 스텝과 의미 매칭된 레퍼런스 스텝 수.
- 매칭: LLM 판정("같은 행동을 지시하는가"), many-to-one 허용(초안 한 스텝이
  레퍼런스 두 스텝을 덮으면 둘 다 매칭), 타임스탬프 ±30초 내만 인정.
- LLM 매칭 결과는 **사용자 대조 1회 이상** 검증 후 확정 (LLM-judge 단독 금지).
### 값 정확도 (Value-F1)
- 대상: 레퍼런스 스텝의 설정값·버튼명·수치 (스텝당 0..n개).
- **값을 두 종류로 분류해 F1을 각각 낸다 (v1.1 추가).** 판별 기준은 단 하나 —
  *"시청자가 따라 하면 자기 화면·계정에도 같은 값이 나타나는가?"*
  - **조작값(operable)**: 그렇다. 메뉴 항목명·버튼명·입력 키워드·설정 수치·경로·제약
    (예: `python3`, "Add Python 3.9 to PATH", "Manage trial" 메뉴 9항목, 감속 `0.98배`,
    DM 키워드 `secret`, 하루 5회 상한).
    → **이것이 주 지표다.** 회귀 비교·라운드 게이트는 조작값 F1으로 판단한다.
  - **인용값(reported)**: 아니다. 저자 개인의 실적·사례 수치
    (예: `16.3x`, `90,991 views`, `20,542 followers`, `April 7`).
    → 슬라이드 판독력의 보조 지표. 따라하기 성패와 무관하므로 게이트에 쓰지 않는다.
- 분류가 애매하면 조작값으로 넣지 말고 인용값으로 내린다(주 지표를 보수적으로 유지).
- 교정 단계에서 사용자에게 **조작값 위주로 질의**한다 — 인용값은 영상 재시청으로만
  판정 가능해 "따라해 본 사람"의 권위가 미치지 않는다.
- 배경: 2편(t1-XAN6AyOs)처럼 저자 실적 수치가 값의 절반을 차지하는 장르가 있어,
  구분 없이 합산하면 편별 F1이 같은 의미의 점수가 되지 않는다.
- 정규화 후 토큰 F1: 쉼표·공백 제거, 전각→반각, "만원/만 원" 통일, %·원 단위 접미
  분리, 한글 숫자(천/만/억)는 아라비아로 전개. 정규화 규칙은 이 문서가 원본이며
  케이스 발견 시 여기에 추가한다.
### 보고 형식
| video | 스텝(참조/초안/매칭) | R1-Recall | 조작값(참조/일치/F1) | 인용값(참조/일치/F1) | 특이 |
비고란에 장르·자막 유무·크롭 재질의 횟수를 기록한다. 영상 길이와 프레임 수도 함께
적는다 — 비용·판독량이 길이에 거의 선형이라 편 간 비교에 필요하다.

## 회귀 사용
라운드 완료 시마다 동일 골든셋으로 재측정해 per-video 증감을 기록한다.
지표 하락이 있으면 해당 라운드는 품질 비저하 게이트 위반으로 취급한다.
