# tuto 비용절감 라운드 3 — 설계 스펙 (본체 모델 티어링)

- 날짜: 2026-08-07
- 상태: 설계 제시 완료, 스펙 리뷰 대기
- 절대 조건: **품질 비저하** — G3 게이트(값 전량 동일·감사 통과) 미달 시 위임 철회.
  라운드1(G2 아님)·라운드2(G2)와 동일한 "게이트가 심판" 규율.

## 1. 배경·근거

라운드2 실측 비용 분해: 본체(프레임 판독+가이드 작성, 세션 모델) 768K = 74%,
감사(Sonnet 6+1 + 재검) 275K = 26%, 스크립트 0토큰. 감사·스크립트는 두 라운드에 걸쳐
최적화 완료 — 남은 지배 항목은 본체 하나다. 라운드2 감사에서 Sonnet은 크롭을 스스로
수행하며 모든 값을 정확 판독했고(가이드의 서식 오류를 잡아낸 것도 Sonnet), 판독력은
실증됐다. 미검증 영역은 서사·스텝 구조화 품질뿐이며 그것이 G3 게이트의 심판 대상이다.

## 2. 설계 결정

### T1. 가이드 빌더 위임 (SKILL.md §4 개정 — 하이브리드 티어링)

- **세션 모델(오케스트레이터)이 유지하는 것**: 패스1 신호 해석, zoom-plan 판정(§2),
  빌더 파견, 표본·커버리지 감사 조율(§5), 누락 후보 처리, 최종 사용자 응답(§7), Q&A.
- **`model: "sonnet"` Agent(가이드 빌더)에 위임하는 것**: 전체 프레임 판독 + guide.md
  작성 + 표본 주장 후보 6건 선정(서식·상태 변화 ≥1건 규칙 포함, 없으면 명시).
- 빌더 입력 계약: FRAME 경로 목록(kept만) + analyze 보고서 경로(자막·챕터·DESC_TIMESTAMPS)
  + §4 가이드 형식·검증 규칙 전문 + 캐시 디렉토리. 재확대가 필요하면 빌더가 직접
  `zoom.py --crop`(영상당 ≤5회)을 수행한다.
- 빌더 출력 계약: `<cache_dir>/guide.md` (감사 스탬프 자리 비움) + 주장 후보 목록
  (주장 문장 + 근거 프레임 경로). 오케스트레이터가 감사를 돌리고 스탬프를 기입한다.
- 불일치 처리: 감사 MISMATCH의 가이드 교정은 오케스트레이터가 수행(현행과 동일).

### T2. 게이트 G3 (채택 조건 — 미달 시 위임 철회)

벤치마크(zP3i_7xZW7Q) E2E에서:
1. **값 동일성**: Sonnet 빌더 가이드의 `(t=)` 인용 값이 기준선(guide-baseline.md)과
   전량 동일. 하나라도 다르면 즉시 철회.
2. **감사 통과**: 가치 6건(교정 발생 시 재검 포함 최종 일치) + 커버리지 감사 정상 동작.
3. **비용 상한**: 분석 1회 생산등가 달러가중 **≤ 700,000** (현행 1,042,717 — 목표 ~45만).
   측정은 message.id dedup + 모델 단가 가중(sonnet 1/5) 방법론.
4. **서사 품질 육안 확인 1회**: 빌더 가이드와 기준선 가이드를 나란히 놓고 구조·요약의
   명백한 퇴행 여부를 오케스트레이터가 판정해 기록한다(정성 — 게이트 1·2를 보완).
미달 시: SKILL.md §4 위임 문구를 원복하는 커밋 + 실측치를 본 스펙에 추기(G2 선례).

### T3. 이연 소품질 동봉 (zoom.py — 라운드2 최종 리뷰 이연분)

1. **크롭 코드 캡**: `--crop` 스펙이 호출당 5건 초과면 평문 ERROR + exit 1
   (SKILL.md의 "영상당 ≤5회" 산문 상한을 코드로 배선).
2. **부분 파일 방어**: 크롭 ffmpeg 실패(RuntimeError) 시 평문 `ERROR:` + 부분 dst
   삭제 + exit 1 (traceback 금지 — 파일 내 fail-loud 관례 정합).
3. **동시 플래그 NOTE**: `--crop`과 `--ranges`/`--timestamps` 동시 지정 시
   stderr에 "NOTE: --crop 지정 시 다른 모드는 무시됨" 1줄 후 crop만 수행(현행 동작 유지).

## 3. 변경하지 않는 것 (범위 외)

- 감사 프로토콜(6+커버리지, Sonnet+크롭, 에스컬레이션) — 라운드2 확정 그대로.
- zoom-plan 판정의 모델 티어 — 세션 모델 유지(신호 해석은 실증 데이터 없이 내리지 않음).
- 컨텍스트 다이어트(자막 파일화·지도 프레임 상한) — G3 결과 확인 후 라운드4 후보.
- 골든셋 1차 측정 — 사용자 URL 제공 시 병행(본 스펙과 독립).

2. G3 4항 전부(§T2) — 값 전량 동일·감사 통과·비용 ≤70만·서사 육안 기록.
