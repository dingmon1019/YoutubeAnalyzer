# solo 모드 — $1 내외·15분 파이프라인 (설계)

- 작성일: 2026-08-18 · 기반 브랜치: `cost-round5` (v0.4.0, 미병합 — 이 라운드와 함께 병합 결정)
- 선행 실측: 라운드5 보고서(`docs/eval/reports/2026-08-18-round5.md`). 요지: 위임 구조를 유지한 절감은 -10.4%가 한계였다. 본체·서브에이전트 이중 청구가 구조적 원인.

## 0. 목표와 비목표

**목표:** `/tuto` 1편(≤30분 영상) 실행을 **$1.5 이하·20분 이하**로 만든다 (내부 목표 $1.2·15분). 방법은 절감 레버 추가가 아니라 **위임 구조 제거**다 — 세션 에이전트 하나가 전 단계를 수행하고, 서브에이전트는 커버리지 감사 1건(haiku)만 띄운다.

**사용자 판단(이 라운드의 전제):** "아무도 30분 영상 한 편에 $10과 40분을 쓰지 않는다. 비용이 무겁다는 사실이 우리의 장점을 전부 상쇄한다." 품질 저하를 감수하더라도 확 가볍게 간다. 산문 오독은 허용하고, 행동에 영향을 주는 값(`command`·`setting`)만 지킨다.

**비목표:**
- 정밀 파이프라인의 품질 재현. 표본 감사·판독/빌더 분리·값 불일치 0건 게이트는 **의도적으로 버린다.**
- 두 모드 공존. SKILL.md에 정밀 경로를 남기지 않는다 — 문서 길이가 곧 매 콜 비용이다. 정밀 파이프라인은 v0.4.0 태그와 git 히스토리로 복원 가능하다.

## 1. watch 대비 존재 의의 — solo 모드에서도 지키는 것

비용이 가벼워지면 "그럼 `/watch`와 뭐가 다른가"가 정당한 질문이 된다. 아래 6개가 답이고, **전부 solo 모드에 남는다.** 하나라도 빠지면 이 스킬은 watch의 비싼 복제품이 된다.

| # | tuto만 있는 것 | watch | solo 유지 방식 |
|---|---|---|---|
| 1 | **`evidence.json` 기계 정본** — 모든 지식이 프레임·타임스탬프·자막 인덱스로 근거 추적되고, 스키마 게이트(`--merge` exit 2)가 근거 위조를 거부 | 자막+프레임을 세션 컨텍스트에 올려 QA — 세션이 끝나면 사라짐 | §2-4단계 그대로. 스키마·머지 게이트 무변경 |
| 2 | **화면 우선 + `conflict` 필드** — 자막이 "16배"라 해도 화면이 "16.3x"면 화면을 채택하고 불일치를 구조화 보존 (실측: reword↔"reward", python↔python3) | 자막 중심, 화면은 보조 | 검증 규칙 유지: 화면값 우선·불일치 병기·`⚠️ 화면 확인 필요` |
| 3 | **지시어 큐 확대** — 자막의 "여기 보세요"·"이 설정"·"클릭" 시점을 골라 그 화면만 고해상 판독 | 균등 샘플 프레임 | 세션 에이전트가 지도 프레임+자막으로 확대 3~4곳 즉석 판정 (§2-2) |
| 4 | **결정론적 교차 대조** — 해시·수치 판독이 갈린 자리를 LLM 비용 0으로 검출 (`--cross-check`) | 없음 | §2-5단계. 라운드5 신규 기능 그대로 |
| 5 | **커버리지 감사** — "뽑았어야 할 지식이 통째로 빠졌는가"를 독립 컨텍스트가 심판. 실측 4편에서 누락 12건 회수한 유일한 검증 단계 | 없음 | **haiku 1건으로 유지** (§2-6). 이미지 0장, 자막+digest만 |
| 6 | **캐시 재질의** — 분석된 영상은 evidence.json으로 재다운로드 없이 후속 질문 응답 | 매번 재시청 | 후속 질문 절 유지 (경량화해 이식) |

**버리는 것 (명시적):** 표본 감사(실측: 4편 24건 판정에서 수정 0건, 주입 6건 중 1건만 표본 포함 — 실효성이 측정으로 부정된 단계), 판독/빌더 역할 분리(지도 프레임 이중 판독 제거), 산문 값의 무오류 보장.

## 2. solo 파이프라인

세션 에이전트가 순차 수행한다. 서브에이전트는 6단계의 haiku 1건뿐이다.

1. **패스1** — `analyze.py <url>` (timeout 600000). 보고서를 `<cache_dir>/pass1-report.txt`로 저장. STATUS 확인, 실패 시 평문 보고(라운드4 폴백 체인 그대로).
2. **지도 판독 + 확대 판정** — 지도 프레임 전량을 **한 응답에서 병렬 Read**하고, 같은 응답에서 확대 지점을 판정한다. 규칙 3개만: ① 읽을 텍스트가 있는 화면 중 값 밀도 상위 3~4곳을 1024로, ② 자막 지시어 큐 시점 우선, ③ 미관측 구간 60초 이상이면 1곳 추가. 별도 zoom-plan.json은 만들지 않는다(위임이 없으니 전달 계약이 불필요).
3. **확대** — `zoom.py <id> --timestamps "...@1024,..."` 1회 호출(1024 최대 4장, 총 6장) → 출력 프레임을 **한 응답에서 병렬 Read**. `--add-frames`로 등록. 크롭 재확대는 1회만.
4. **evidence** — `evidence-patch.json`을 **1회 Write** → `evidence.py --merge`. exit 2면 INVALID를 보고 1회 수정 재시도. 스키마·검증 규칙(화면 우선·conflict·행동 가능한 content) 전부 유지하되, `verification.status`는 전 항목 `unaudited`로 남는다(표본 감사 없음 — 스탬프에 명시).
5. **교차 대조** — `evidence.py --cross-check`. flag가 나오면 해당 프레임만 재확인해 값을 확정하고 merge로 정정.
6. **커버리지 감사 (유일한 서브에이전트)** — `model: "haiku"` Agent 1건. 입력은 `--coverage-input` 출력 + 자막 전문 경로. **이미지 Read 금지를 프롬프트에 명시**(비용 상한의 핵심). 반환된 누락 후보는 자막으로 재확인해 명백한 것만 merge 보강(1회 한정).
7. **video.md** — **1회 Write** (Edit 반복 금지). 헤더에 검증 범위와 함께 **"표본 감사 미실시 — 근거는 추적 가능하나 독립 검증되지 않음"** 을 명시한다. 정직성이 정밀 모드 제거의 대가다.
8. **응답** — 요약 + 두 산출물 경로 + 자연어 요청 계속 수행(기존 §7 계약 유지).

## 3. SKILL.md 전면 재작성

- 현재 20,410자(~8,164토큰)가 매 콜 본체에 재청구된다. **목표 6,500자(~2,600토큰) 이하.** 위임 지시·판정 루브릭 전문·표본 감사 절차·N=M 검사 등 위임 전용 내용이 전부 삭제 대상이다.
- 유지하는 계약: 단일 인터페이스(`/tuto <url> [요청]`), 분석 후 요청 계속 수행, 화면 우선·conflict·⚠️ 규칙, gaps 정의, 후속 질문 캐시 우선, 실패 시 평문 보고, §1의 6개 차별점.
- `tests/test_skill_contract.py`는 solo 계약으로 재작성한다 — **이 파일만 append-only 예외를 허용한다**(문서 전면 교체이므로 기존 문구 단언이 대량 무효화된다). 삭제되는 테스트와 사유를 커밋 메시지에 나열한다. 새 계약 테스트에 **문서 길이 상한**(`len(TEXT) < 7000자`)을 포함해 "문서가 다시 자라는" 회귀를 막는다.

## 4. 스크립트 변경 (최소)

- `analyze.py` — `allocate_map_budget`의 `n = min(40, max(12, round(duration/60*1.2)))` → `min(16, max(6, round(duration/60*0.7)))`. 11:27 영상 기준 14 → 8장. 30분 영상 21 → 16장 캡.
- `zoom.py` — 무변경 (크롭 캡 2는 라운드5 값 유지, SKILL.md가 1회로 더 조인다).
- `evidence.py` — `audit_candidates(limit=6)` 기본값을 3으로 정합(라운드5 이월 minor). 표본 감사가 없어져도 함수는 교차 대조 후보 노출용으로 남는다.
- 기타 스크립트 무변경. 정밀 파이프라인 스크립트는 삭제하지 않는다 — SKILL.md가 안 쓸 뿐이다.

## 5. 게이트 (완화된 기준 — 사용자 승인됨)

같은 영상(`7MEsgHKQGLg`)으로 전용 세션 실측 1회. `compare-evidence.py`는 참고 지표로만 쓰고, 판정 기준은 아래로 교체한다.

1. **`command`·`setting` 오독 0건** — before(v0.3.3 산출물)의 command·setting 항목과 수동 대조. 산문 오독은 허용.
2. 지식 항목 **60% 이상** 유지 (35건 기준 21건 이상).
3. **비용 $1.5 이하** (`measure-cost.py`, 전용 세션 규약).
4. **시간 20분 이하.**
5. **조기 중단 조건:** 실측 중 세션 에이전트 콜이 20을 넘으면 그 자리에서 중단하고 재설계한다 — 라운드5에서 반증된 "프롬프트 지시로 행동 통제" 가정에 다시 기대는 부분이 있으므로, 지시가 안 먹히면 빨리 안다.

**롤백 규칙:** 게이트 실패 시 solo SKILL.md를 버리고 v0.4.0 SKILL.md로 복원한다(파일 교체 1회). 스크립트 변경(§4)은 독립 커밋이라 개별 롤백.
